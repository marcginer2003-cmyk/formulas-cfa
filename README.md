# Fórmulas CFA · Puzle

Web app para aprender las fórmulas del CFA Level I montándolas como un puzle (tipo Duolingo).

- 377 fórmulas de los 9 temas
- Modos: Al azar, Por temas y Las que más fallo
- Funciona sin conexión una vez instalada

**Instalar en el iPhone:** abre la página en Safari → Compartir → Añadir a pantalla de inicio.
